# 放課後フラッグパニック

『パワプロクンポケット』裏サクセスのような、拠点探索型サバイバルRPGを目指すブラウザゲームのプロトタイプです。

## 実装場所

- `index.html`: 画面構造とゲームのエントリーポイント。
- `styles/main.css`: レイアウト、マップ、パネル、モーダルの見た目。
- `src/game-core.js`: 探索ルール、戦闘、日数・食料管理、仲間救出、セーブデータ変換などのゲームロジック。
- `src/main.js`: 画面描画、入力処理、モーダル、ローカルストレージ保存/読込などのブラウザ連携。
- 画像バイナリは未コミット: ブランチ更新システムがバイナリファイルを拒否するため、現在の視覚表現はCSSグラデーションとテキストバッジで構成。

## 現在できること

- 学校前の14×14町内マップを移動し、町内にある「拠」マスへ入った時だけ休息・配給・治療を選択。校内入口は初期位置のすぐ近くに配置。
- CSS背景と装飾レイヤーを持つ14×14の探索マップを上下左右に移動し、表示は主人公周囲の25マスに限定。箱・窓・棚・店先などの装飾は通行不可の障害物として迷路に影響。
- 校内・商店街・公園・空き地は階段/抜け道で複数階層化され、階層を切り替えながら突破。
- 探索先だけでなく拠点前の町内でも敵シンボルと読み合い戦闘。
- アイテム取得、イベント選択、仲間救出。
- 日数、時間帯、食料、薬、部品、士気、旗汚染、旗圧（旗人間の包囲）の管理。
- 第一章は校内探索、アカリ救出、ロッカー確認、放送室の退路確保、部品確保を軸に進行。
- イベント選択で「物資を取って旗圧を上げる」「安全を取って旗圧を下げる」などのリスク/リターンが変化。
- 通信機部品を3つ集めると町内に空き地が出現し、ラストダンジョンの通信塔跡を突破すると第一章クリア。

## デモ画像

ブランチ更新システムがバイナリファイルをサポートしないため、デモPNGや実画像ファイルはコミットしていません。現在はCSSだけでデモ相当の見た目を再現し、将来バイナリを扱える配布経路でPNG画像を追加する方針です。

## ローカルでの起動方法

### ワンクリック起動

依存パッケージは不要です。OSに合わせて以下のファイルをダブルクリックしてください。

- Windows: `play.bat`
  - Pythonが無くても、Windows標準のPowerShellでローカルサーバーを起動してブラウザを開きます。直接押すのは `play.bat` だけでOKです。
  - `play.bat` が関連付けなどで開けない場合は、同じ内容の `play.cmd` をダブルクリックしてください。
- macOS / Linux: `sh play.command`（または実行権限を付けたうえで `./play.command`）

起動すると自動でブラウザを開きます。ブラウザが開かない場合は、手動で以下を開いてください。

```text
http://127.0.0.1:8000
```

終了するときは、起動した黒い画面/ターミナルで `Ctrl+C` を押すか、ウィンドウを閉じてください。

### 手動起動

うまく起動しない場合は、任意の静的HTTPサーバーで起動できます。

```bash
python3 -m http.server 8000
```

## テスト方法

ゲームロジックとブラウザ配線のスモークテストはNode.js標準のテストランナーで確認できます。

```bash
npm test
```

構文チェック（`src/game-core.js` / `src/main.js`）と全テストをまとめて実行する場合は以下です。

```bash
npm run check
```

ブランチ更新用パッチがバイナリを含まず、ベースコミットへ実際に適用できるかを確認する場合は以下です。

```bash
npm run verify:branch-update
```


## ブランチ更新エラーについて

このリポジトリの現在の `HEAD` は画像・実行ファイル・フォントなどのバイナリを含まないテキストのみの差分です。`npm run verify:branch-update` は、`HEAD~1` から `HEAD` への実際の更新パッチを生成し、バイナリパッチではないことを確認してから fresh な `HEAD~1` worktree に適用します。

それでも「バイナリファイルはサポートされません」と表示される場合、原因は現在の `HEAD` ではなく、更新先として残っている古いブランチ/PRに過去のPNGなどのバイナリblobが含まれていることです。その状態で同じブランチを更新しようとすると、更新システムが古いバイナリ差分の削除・置換も扱おうとして失敗します。対処は、古いPRブランチを削除してこの履歴から作り直すか、バイナリを一度も含まない新しいブランチ名でPRを作成することです。

## デバッグ起動

一章クリア状態、資源MAX、即エンディングの検証ボタンは通常非表示です。以下のように `debug=1` を付けると表示されます。

```text
http://127.0.0.1:8000/?debug=1
```

## 操作方法

- 拠点マップ: 学校前の町内を歩き、「拠」マスで休息・配給・治療、校内・商店街・病院・公園の看板マスで探索先へ移動。部品が揃うと空き地への入口が出現。
- 移動ボタン: 5×5マップ表示のすぐ横にある矢印ボタンで移動。
- キーボード: 矢印キーまたはWASDで移動。
- 出口マス: 「出」に乗ると拠点へ帰還可能。商店街などから帰還した場合は、町内でもその探索先の前から再開。
- 階段/抜け道: 「2F」「裏」「丘」などのマスに乗ると同じ探索先の別階層へ移動。
- 障害物: 箱・窓・棚・店先・物資山などは通れない。道・草・扉などは地形の目印として通行可能。
- 探索先の危険度: 探索から帰還すると上がり、休むと基礎値に向かって下がる。危険度が高い場所では追加の敵が出現する。
- 章進行: 第一章はボタンでは完了しない。部品を3個集めて町内に出現する空き地へ入り、通信塔跡の最深部イベントを突破すると完了。
- 目標: 拠点パネルで通信機修理、痕跡集め、仲間救出、旗圧抑制、夜襲抑制の進捗を確認できる。
- 探索メモ: エリアごとの探索回数、回収物資、確認イベント、撃破敵、救出仲間を確認できる。
- 戦闘: 敵の構えを見て「突く」「守る」「誘導」「逃げる」を選ぶ読み合い方式。正解すると被害と旗圧を抑え、読み違えるとHP・旗汚染・旗圧が悪化。
- 配給方針: 町内の「拠」マスに入った時だけ標準・節約・厚めを切り替え、夜明けの食料消費と士気変化を調整できる。
- 薬を使う: 町内の「拠」マスに入った時だけ薬を1つ消費し、選んだ仲間のHPを18回復して旗汚染を12下げる。
- 仲間の個性: アカリがいると応急手当により休息と薬の回復効果が上がり、シュンがいると探索物資の入手量が少し増え、ミナトが健在なら戦闘や夜襲の被害を少し抑える。
- 夜襲: 危険度が高すぎる探索先を放置すると、日付更新時に拠点が襲われてHPと士気が下がる。
- 痕跡: イベントで事件の手がかりを集めると、救助信号時のエンディングが調査継続ルートに変化する。
- 探索オブジェクト: 一度調べたイベントや回収した物資は再配置されないため、痕跡や報酬は周回探索で無限回収できない。
- セーブ/ロード: ブラウザのローカルストレージに現在の進行状況を保存し、次回以降に再開できる。
- 移動時間: 探索中に歩き回るだけでも一定歩数で時間が進み、日付更新・食料消費・時間切れのリスクが発生。
