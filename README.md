# 放課後フラッグパニック

『パワプロクンポケット』裏サクセスのような、拠点探索型サバイバルRPGを目指すブラウザゲームのプロトタイプです。

## 実装場所

- `index.html`: 画面構造とゲームのエントリーポイント。
- `styles/main.css`: レイアウト、マップ、パネル、モーダルの見た目。
- `src/main.js`: ゲーム状態、探索マップ、戦闘、日数・食料管理、仲間救出、イベント処理。

## 現在できること

- 学校拠点から探索先を選択。
- 10×10の探索マップを上下左右に移動。
- 敵シンボルとの接触戦闘。
- アイテム取得、イベント選択、仲間救出。
- 日数、時間帯、食料、薬、部品、士気、旗汚染の管理。
- 通信機部品を3つ集めると救助信号を送ってクリア。

## ローカルでの起動方法

### ワンクリック起動

依存パッケージは不要です。OSに合わせて以下のファイルをダブルクリックしてください。

- Windows: `play.bat`
  - 裏で `open-browser.bat` がブラウザを開きます。直接押すのは `play.bat` だけでOKです。
- macOS / Linux: `play.command`

起動すると自動でブラウザを開きます。ブラウザが開かない場合は、手動で以下を開いてください。

```text
http://127.0.0.1:8000
```

終了するときは、起動した黒い画面/ターミナルで `Ctrl+C` を押すか、ウィンドウを閉じてください。

### 手動起動

うまく起動しない場合は、任意の静的HTTPサーバーで起動できます。

```bash
python3 -m http.server 8000
```

## テスト方法

ゲームロジックはNode.js標準のテストランナーで確認できます。

```bash
npm test
```

構文チェックとテストをまとめて実行する場合は以下です。

```bash
npm run check
```

## 操作方法

- 探索先ボタン: 校内、商店街、病院、公園へ移動。
- 移動ボタン: 画面下の矢印ボタンで移動。
- キーボード: 矢印キーまたはWASDで移動。
- 出口マス: 「出」に乗ると拠点へ帰還可能。
- 探索先の危険度: 探索から帰還すると上がり、休むと基礎値に向かって下がる。危険度が高い場所では追加の敵が出現する。
- 章進行: 第一章は校内探索、アカリ救出、ロッカー確認、部品1個確保で完了し、報酬を得て第二章へ進める。
- 目標: 拠点パネルで通信機修理、痕跡集め、仲間救出、夜襲抑制の進捗を確認できる。
- 探索メモ: エリアごとの探索回数、回収物資、確認イベント、撃破敵、救出仲間を確認できる。
- 偵察: 拠点で1区切り消費して、未救助の仲間・イベント・物資・追加敵から有望な探索先を確認できる。
- 作戦変更: 拠点で標準・慎重・強行を切り替え、戦闘時の攻撃力、被害、旗汚染、逃走率を調整できる。
- 配給方針: 拠点で標準・節約・厚めを切り替え、夜明けの食料消費と士気変化を調整できる。
- 薬を使う: 拠点で薬を1つ消費し、選んだ仲間のHPを18回復して旗汚染を12下げる。
- 仲間の個性: アカリがいると応急手当により休息と薬の回復効果が上がり、シュンがいると探索物資の入手量が少し増え、ミナトが健在なら戦闘や夜襲の被害を少し抑える。
- バリケードを作る: 拠点で部品を1つ消費し、危険度が上がった探索先を補強して危険度を2下げる。
- 見張り当番: 拠点で1区切り消費して警戒レベルを上げ、次の夜襲被害と士気低下を軽減できる。
- 夜襲: 危険度が高すぎる探索先を放置すると、日付更新時に拠点が襲われてHPと士気が下がる。
- 痕跡: イベントで事件の手がかりを集めると、救助信号時のエンディングが調査継続ルートに変化する。
- 探索オブジェクト: 一度調べたイベントや回収した物資は再配置されないため、痕跡や報酬は周回探索で無限回収できない。
- セーブ/ロード: ブラウザのローカルストレージに現在の進行状況を保存し、次回以降に再開できる。
- 屋上から救助信号を送る: 部品3つでクリア。
